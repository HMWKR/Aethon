# Aethon 비교 대상의 공개 요금과 제작비

조사일: **2026-10-27**. 아래는 각 사업자가 공시한 가격과 조건이다. 실제 거래액이나 Aethon의 판매 가격·제작 원가·고객의 지불 의향을 측정한 수치가 아니다. 각 페이지의 게시일은 확인되지 않아 조회일만 기록했다. 가격·조건은 변경될 수 있으므로 대외 자료에 사용하기 직전 다시 확인한다.

## 국내 전문 제작 사례: 밍글스튜디오

[서비스·요금 안내](https://minglestudio.co.kr/services)의 원테이크 뮤직비디오 안내는 약 3분 영상의 모션캡처 스튜디오 대여 시작가를 **60만 원부터**, 권장 대여 금액을 **60만~80만 원**으로 표시한다. 촬영은 3~4시간을 기준으로 하고, 촬영 진행 인건비 **시간당 5만 원**이 추가된다. 편집과 아바타·배경·프랍은 별도이며 모든 가격은 **부가세 별도**다.

같은 페이지는 기획부터 납품까지 지원하는 프리미엄 뮤직비디오 제작의 예상 비용을 **200만~400만 원**으로 제시한다. 제작 범위와 연출에 따라 상담 후 견적이 달라진다. 이 금액은 특정 공급자의 견적 안내이며 거래의 평균값이나 확정 금액이 아니다.

**사용 범위:** 사람·모션캡처·후작업이 포함될 수 있는 전문 제작 대안을 설명하는 사례로 적합하다. 스튜디오 대여 시작가와 완성작 가격을 혼동하지 않는다. Aethon이 동일한 품질·인력·범위를 대체하거나 해당 금액만큼 절감한다는 주장의 근거로 사용할 수 없다.

## 생성형 영상 서비스: Runway

[Runway 개인 요금제](https://runway.com/pricing)는 연간 결제 화면에서 Standard를 **월 환산 미화 12달러, 월 625크레딧**, Pro를 **월 환산 28달러, 월 2,250크레딧**으로 제시한다. 해당 환산액에 12개월을 곱하면 각각 연 144달러와 336달러다. 페이지의 해당 표시 조건은 **연간 청구**이며, 월별 결제 가격이나 세금 포함 금액으로 단정하지 않는다.

[Runway 크레딧 안내](https://help.runwayml.com/hc/en-us/articles/15124877443219-How-do-credits-work)에 따르면 Gen-4.5 생성에는 초당 **12크레딧**이 든다. Standard·Pro의 월 지급 크레딧은 결제일에 만료되며, 웹 요금제 크레딧과 API 크레딧은 별개다. 생성 초수는 재시도 및 버려지는 결과를 포함할 수 있으므로 완성 영상의 길이나 품질을 뜻하지 않는다.

**사용 범위:** 생성 서비스의 공개 구독 구조와 사용량 제약을 비교하는 자료다. 구독료만으로 제작 인력·편집·저장·권리 확인 비용까지 포함한 총비용을 계산하거나 Aethon과 동일한 기능 범위라고 판단할 수 없다.

## API 원가의 단순 예시: Runway Dev

[Runway Dev API 요금](https://docs.dev.runwayml.com/guides/pricing/)은 **1크레딧당 미화 0.01달러**, `gen4.5` 영상 생성 **초당 12크레딧**을 표시한다. 따라서 표기 단가를 곱한 예시는 **생성 1초당 0.12달러**, 5초 한 번 생성에 **0.60달러**다. 이는 단순 계산이며 세금, 실패·재시도, 다른 모델, 이미지·음성·편집·인프라 및 인건비는 포함하지 않는다. 페이지는 지역에 따라 판매세가 적용될 수 있다고 안내한다.

**사용 범위:** 공개된 특정 모델의 입력 가정으로 시나리오를 설명할 수 있다. 실제 Aethon의 선택 공급자·계약 단가·청구액·완성 영상 1초의 원가가 확인됐다는 의미가 아니다. 위 웹 구독료에 포함된 크레딧을 API에서 사용할 수 있다고 계산하지 않는다.

## 영상 제작 도구: LTX Studio

[LTX Studio FAQ](https://website.ltx.studio/studio/faq)는 무료 요금제에 **일회성 800크레딧**, 상업적 프로젝트에 필요한 유료 요금제는 **월 15달러부터**라고 안내한다. 해당 FAQ는 이 시작가에 적용되는 청구 주기, 세금, 유료 제공량과 지역별 가격을 명확히 표시하지 않는다. 결제 전 최신 요금표에서 확인해야 한다.

**사용 범위:** 독립 제작자가 접할 수 있는 영상 제작 서비스의 공개 시작가 사례다. Aethon의 적정 가격이나 양 서비스의 동일한 생성량·결과물 수준을 증명하지 않는다.

## 사업계획과 발표자료 반영 기준

- 업체·통화·정확한 제공 범위·기준일을 수치와 함께 기재한다. 외주 견적과 도구 구독료는 서로 다른 범위이므로 단순 차액을 절감 효과로 제시하지 않는다.
- 공급자 공개 요금은 관찰된 가격이지 해당 시장의 평균, 전체 시장 규모, 실제 구매 수요가 아니다.
- Aethon의 가격·실청구·인건비·고객 수·매출과 단위경제성은 별도 근거를 확보하기 전 미확인으로 유지한다.
