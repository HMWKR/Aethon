## 2026-04-20: Phase 1 사전 지식 시드

### 3막 구조 vs Kishōtenketsu
- **발견**: 서구 표준은 3막(Setup-Confrontation-Resolution), 동아시아는 4단 Kishōtenketsu(기-승-전-결, 갈등 없는 전환 강조). 일본/한국 시장 대상 콘텐츠는 후자 적합.
- **이유**: P1 P2 페르소나는 한국 창작자 — 한국·일본 진출 시 Kishōtenketsu 옵션 제공이 자연스러움.
- **영향**: Phase 8 스토리텔링 어시스턴트에 두 구조 모두 검증 룰셋.
- **출처**: 사전 리서치.
- **다음**: Phase 8 구현 시 두 구조 분기.

### 감정 곡선 측정
- **발견**: 씬별 emotion(calm/anger/battle 등)을 시계열로 시각화하면 영상의 정서적 흐름 가시화. 이상적인 곡선 패턴: 도입(낮음) → 갈등 점진(중간) → 클라이맥스(최고) → 해소(중간) → 결말(낮음).
- **이유**: 일관된 톤보다 변화의 곡선이 시청자 몰입에 효과.
- **영향**: Phase 8에서 Recharts 시계열 차트 + "감정 변동 점수" 계산. 너무 평탄하거나 너무 들쭉날쭉한 경우 알림.
- **출처**: 사전 리서치 + 영상 문법.
- **다음**: Phase 8 알고리즘 설계.

### 영화적 그래마 체크리스트 — 180도 법칙 등
- **발견**: 시각적 일관성 핵심 룰 — (a) 180도 법칙(축선 유지로 인물 위치 일관), (b) 30도 법칙(컷 간 카메라 각도 30도+), (c) 시선 일치(eye-line match), (d) 컷 연속성(motion match).
- **이유**: AI가 영화 문법을 자연스럽게 따르지 못함 → 검증 룰로 보완.
- **영향**: P5(영화감독) 페르소나의 핵심 가치. Phase 8에서 룰 위반 시 알림 + 자동 수정 제안.
- **출처**: 사전 리서치 + 영화 이론.
- **다음**: Phase 8 룰 엔진 구현.
