## 0. One-Line Vision

> **"AI advises. You choose. The timeline remembers."**
>
> AETHON은 전 세계 AI 영상 창작자가 **최종적으로 돌아오는 AI-native 편집 표준**이 된다. 여러 이미지/영상 AI를 한 프로젝트 타임라인에서 비교하고, AI는 더 나은 선택지와 놓친 리스크를 제안하며, 사용자가 책임 있게 결정한다.

## 1. Problem We Solve

### 1.1 기존 도구의 한계

현재(2026년 4월 기준) AI 영상 도구는 두 종류다:

- **단발 모델 도구** (Runway / Kling / Pika / Sora 등): 한 컷의 품질은 뛰어나지만, **씬 간 캐릭터·배경·그림체 일관성이 무너진다**. 각 모델별 강점이 다르지만 사용자는 한 도구만 선택해야 한다.
- **편집기 도구** (CapCut / Premiere / DaVinci 등): 컷 편집·자막·음악은 강력하지만, **AI 생성을 1차 자산으로 통합하지 못한다**. 외부 도구에서 생성한 클립을 import만 가능.

> **빈 자리**: "AI 생성 + 일관성 + 타임라인 편집 + 선택 근거 기록"을 단일 워크플로우로 통합하는 도구. AETHON이 정의하는 카테고리는 **AI-native NLE**다.

### 1.2 창작 병목 정량화 (가설)

| 활동 | 현재 (Runway 단독) | AETHON 목표 | 단축률 |
|---|---|---|---|
| 5분 영상 1편 제작 | 평균 12시간 | 평균 3.6시간 | **-70%** (S2) |
| 매 씬 프롬프트 재입력 | 30회 (씬마다) | 1회 (캐릭터 카드) | **-95%** |
| 캐릭터 일관성 검증 라운드 | 5~10회 재생성 | 0~2회 (IP-Adapter 자동) | **-80%** |
| 인페인트 부분 수정 | 외부 도구 왕복 | 인라인 핀 1클릭 | **단계 -3** |

> 위 수치는 D+60 베타 출시 후 내부 사용자 3명 + 외부 10명을 대상으로 검증한다(S2 측정).

### 1.3 시장 변화 신호 (2026년)

- **모델 다변화**: 2024년 Runway 독점 → 2025~2026년 Kling/Veo/Seedance/Sora 2/Hailuo 등 9+개 모델로 분화. 각 모델 강점 차별화 → **메타 라우터 수요** 발생.
- **창작자 경제 성장**: 1인 크리에이터 시장 확대 (YouTube/TikTok 영상 생산자 규모 확대 추정).
- **B2B 수요 신호**: 광고/게임/교육 분야의 사전 시각화 수요. 외주 단가 인상 → 내부 도구화 압력.

## 3. 북극성 지표 (North Star Metric)

### 3.1 1차 후보: **월간 완성 영상 수 (MAFV — Monthly AI-Finished Videos)**

> **정의**: 한 달 동안 AETHON에서 시작 → MP4 Export까지 완료된 영상 수.

**왜 이 지표인가**:
- 단순 가입자 수가 아닌 **실제 가치 산출** 측정.
- "프롬프트 입력 95% 감소"의 효과가 누적되어 나타나는 지표.
- 사용량 기반 결제 모델로 직접 연결 가능.

**1년 목표**: MAFV 5,000편 (베타 1000명 × 평균 5편).
**3년 목표**: MAFV 250,000편.
**5년 목표**: MAFV 5,000,000편.

### 3.2 2차 보조 지표: **창작자 1인당 평균 제작 시간 단축률**

> **정의**: 동일 영상을 AETHON / 경쟁 도구로 제작했을 때의 시간 비교 (S2와 동일 정의).

**왜 보조인가**: MAFV는 "양", 시간 단축은 "질"의 검증. 양만 늘고 질이 떨어지면 진짜 가치가 아님.

### 3.3 안티-지표 (Hard Limits)

다음이 위반되면 북극성 지표가 좋아도 **잘못된 방향**으로 판단:

- **AI 비용 비율** > 매출의 60%: 단가 협상 또는 자체 모델 검토 (피벗 트리거 T3).
- **창작자 1인당 LTV** < $50: B2B 피벗 검토 (T1).
- **API 호출 매출 비중** > 70%: 헤드리스 플랫폼 재정의 (T2).

## 4. 확장 시나리오 (5축)

### E1. 글로벌 진출 (한 → 일 → 중 → 영어)

**가설**: AI 영상 일관성 문제는 언어 무관하지만, 9개 영상 모델 중 일부는 언어/문화 편향이 있다 (Hailuo는 아시아, Runway는 영어권 유리). AETHON의 라우터가 이 편향을 활용해 시장별 차별화 가능.

**1년 (D+360)**: 한국어 + 일본어 출시.
**3년 (D+1080)**: 영어 + 중국어 + 스페인어. 5개 언어.
**5년 (D+1800)**: 7~10개 언어. 글로벌 7개 거점.

**기술적 함의**: `next-intl` + 9 영상 모델별 다국어 프롬프트 정규화 레이어 + 문화적 편향 라우팅 룰 추가.

### E2. 모바일 앱 (iOS / Android)

**가설**: 데스크톱 타임라인 UX는 그대로 모바일에 가져갈 수 없다. 모바일 = "짧은 영상 (15~60초) + 1~3 캐릭터 + 1~2 컷"의 단순화된 UX.

**기술 선택지**:
- Expo + React Native (Tauri 코드 재사용 어려움)
- Capacitor + 웹뷰 (코드 재사용 ↑, 성능 ↓)
- 네이티브 (성능 ↑, 코드 분기 ↑)

**MVP 후 1년**: Expo 기반 베타. AETHON 웹/데스크톱과 클라우드 동기화.
**3년**: 모바일 + 웹/데스크톱 매출 동등.

### E3. API 플랫폼화 (AETHON Consistency API)

**가설**: 우리의 핵심 IP는 "9 모델 추천/승인 레이어 + IP-Adapter 일관성 엔진 + 선택 근거 로그". 다른 영상 툴(Premiere 플러그인, CapCut Web, 게임 엔진)이 이를 호출하면 SaaS-on-SaaS 레이어 형성.

**제공 API**:
- `POST /v1/route-model` — 씬 메타 입력 → 최적 모델 후보, 대체안, 비용/권리/품질 리스크 추천.
- `POST /v1/consistency-bind` — 캐릭터 레퍼런스 + 프롬프트 → IP-Adapter 적용 이미지.
- `POST /v1/inpaint-pin` — 영역 + 코멘트 → 인페인팅.

**3년**: API 호출이 매출의 30% 차지.
**5년**: 영상 도구 표준 컴포넌트로 자리잡음.

### E4. 크리에이터 마켓플레이스

**가설**: 사용자가 정성껏 만든 캐릭터/세계관/그림체 프리셋은 **재사용 가치가 있는 자산**이다. 거래 시장이 형성되면 네트워크 효과 발생.

**상품 유형**:
- 캐릭터 카드 (외형 + 레퍼런스 이미지)
- 세계관 바이블 (world_bible + 배경 + 그림체 토큰)
- 영상 템플릿 (씬 시퀀스 + 카메라 무브 + 모델 선택)

**수수료**: 거래액의 30% (App Store 패턴).
**3년**: 거래액 월 1억원 / 5년: 월 100억원.

### E5. 영상 학교 / 교육 모듈

**가설**: AI 영상 제작 = 새 직업군. 가르치는 사람이 부족. AETHON 도구 + 콘텐츠 + 커뮤니티를 결합한 교육 사업.

**구조**:
- 무료 튜토리얼 (도구 사용법)
- 유료 마스터클래스 (스토리텔링 + AI 모델 활용 전략)
- AI 영상 학사/석사 과정 (대학 제휴)

**5년**: 매출의 5~10% 차지. 브랜드 강화 효과.

## 5. 피벗 가능성 + 트리거 조건

### T1. B2B 피벗

**트리거**: 개인 창작자 LTV가 D+360 시점에 $50 이하로 수렴.
**대안 시장**: 광고 에이전시(브랜드 일관성 강점) / 게임 스튜디오(사전 시각화) / 교육 콘텐츠 회사.
**제품 변화**: 팀 워크스페이스 + 결재 워크플로우 + 브랜드 자산 라이브러리 + SOC 2 인증.

### T2. API 우선 피벗 (헤드리스 플랫폼)

**트리거**: API 호출 매출이 D+1080 시점에 자체 UI 매출의 70% 초과.
**제품 변화**: 자체 UI 유지보수 최소화 → API 단독 플랫폼. 통합 SDK 제공 (JS/Python/Go/Rust).
**조직 변화**: Sales 인력 → Developer Relations로 전환.

### T3. 수직 통합 (자체 AI 모델)

**트리거**: AI 모델 비용이 매출의 60% 초과 + 외부 모델 의존도가 사업 리스크화.
**대응**: 오픈 모델(Stable Diffusion 계열) 파인튜닝 → 자체 일관성 모델. 또는 모델 회사 인수 검토.
**리스크**: 자본 집약적. Series B 이후만 가능.

### T4. 수직 도메인 특화 피벗

**트리거**: 특정 도메인(예: 광고 / 교육 / 게임 시네마틱)에서 매출의 50%+ 발생.
**대응**: 해당 도메인 특화 워크플로우/템플릿 강화. 다른 도메인 기능 deprecate 검토.

### T5. 인수합병 (Exit)

**트리거**: D+1800 (5년) 시점 추정 가치 확보. 타깃 인수자: Adobe, Canva, Vercel, OpenAI, ByteDance.
**조건**: 핵심 IP(일관성 엔진)와 사용자 베이스 동시 확보.

## 6. 5년 후 AETHON의 모습 (가상 시나리오)

### Scene 1 — 도쿄 어느 카페, 2031년

서연(VTuber, 28세)은 카페에서 노트북을 연다. AETHON 모바일 앱이 어제 만든 90초 인트로의 마지막 씬을 동기화했다. 그녀는 노트북에서 데스크톱 IDE를 열어 한 컷의 색감을 인라인 핀으로 수정한다. "여기 눈빛만 더 강렬하게." 5초 후 결과가 나오고, 그녀는 적용을 누른다.

옆 테이블의 광고 PD 이정훈(47세)은 클라이언트와 영상 통화 중이다. 클라이언트가 "로고 색을 살짝 더 채도 높게"라고 말하자, 그는 화면 공유 상태에서 인라인 핀을 그리고 코멘트를 입력한다. AETHON이 8초 만에 수정본을 보여준다. 클라이언트는 "OK, 이대로 진행하시죠"라고 한다.

두 사람은 어떤 AI 모델로 어떤 씬을 만들었는지 잊지 않는다. AETHON이 추천 이유, 비용, 권리 상태, 수정 이력을 타임라인에 남겼기 때문이다. AI가 대신 책임지는 것이 아니라, 사용자가 더 나은 선택을 하도록 도왔다.

## 7. 이 비전을 지키는 4대 원칙

1. **창작자가 책임 있는 결정권자다**: AI는 대신 결정하지 않는다. 더 나은 선택지, 놓친 리스크, 실행 근거를 제안한다.
2. **선택의 자유를 박탈하지 않는다**: 기본은 Adviser Mode다. Auto는 사용자가 허용한 반복/저위험 작업에만 적용하고, Off도 항상 가능해야 한다.
3. **일관성은 협상 불가능하다**: 캐릭터·세계관·그림체 일관성은 AETHON의 정체성. 어떤 비용 절감도 이 축을 양보하지 않는다.
4. **프로젝트 기억이 해자다**: 프롬프트, 모델, 비용, 권리, 재생성 이유, 사용자의 선택을 타임라인에 남긴다.
5. **속도와 비용은 끝까지 추구한다**: AI 비용 효율을 사용자에게 환원하되, 품질/권리 리스크를 숨기지 않는다.
