Loop 8 - Adviser Decision Workflow and Export Gate

Updated: 2026-05-03 22:51 KST Project: AETHON Scope: UI/UX, editor interaction, production smoke verification Confidence: high, verified by pnpm production:check and Playwright screenshots

Problem

AETHON의 핵심 원칙은 AI가 자동 실행자가 아니라 사용자의 더 나은 선택을 돕는 adviser라는 점이다. 기존 smoke는 editor shell과 export blocker를 확인했지만, 사용자가 AI suggestion을 승인, 수정 적용, 보류했을 때 pending decision과 export readiness가 실제로 함께 변하는지 충분히 증명하지 못했다.

Decision

Loop 8의 중심을 clip 선택 자체가 아니라 Adviser decision workflow로 고정한다. 사용자는 AI suggestion의 근거, 비용, 리스크를 본 뒤 Approve, Edit Apply, Hold 중 하나를 선택한다. 그 결정은 pending/accepted metric에 반영되고, export gate는 남은 AI decision, QC failure, rights review, preview render blocker를 계속 표시한다.

Selected Option

  • AI Adviser decision을 e2e 테스트의 핵심 흐름으로 만든다.
  • timeline clip 선택, inspector context, tool rail 상태를 함께 검증한다.
  • 모든 AI decision을 처리해도 QC/rights/render blocker가 남으면 export는 계속 disabled로 둔다.

Rejected Options

  • 단순 clip selection smoke만 추가한다.
  • AI mode toggle만 추가하고 decision/export 관계는 검증하지 않는다.
  • export gate를 AI pending count만으로 열리게 한다.

Implementation

  • apps/web/app/studio-client.tsx: inspector tab, tool rail, timeline clip, AI metric, export button selector를 보강했다.
  • select-clip reducer는 clip 선택 시 inspectorTab: "clip"으로 전환한다.
  • apps/web/tests/e2e/studio.smoke.spec.ts: Playwright smoke를 18개로 확장했다.
  • 신규 smoke는 explicit adviser decision, all decisions handled, risky generated clip validation, tool state persistence를 desktop/mobile에서 확인한다.

Dark Pattern Review

  • False urgency: avoided. AI suggestion 상태는 실제 pending/blocker만 표시한다.
  • Forced action: avoided. 사용자는 Approve, Edit Apply, Hold를 선택할 수 있다.
  • Confirm shaming: avoided. Hold가 나쁜 선택처럼 표현되지 않는다.
  • Drip pricing: avoided. 비용 metric과 provider cost range를 노출한다.
  • Bait and switch: avoided. AI mode toggle은 provider 실행으로 즉시 이어지지 않는다.
  • Interface interference: avoided. export disabled 상태는 blocker 이유와 함께 제공된다.
