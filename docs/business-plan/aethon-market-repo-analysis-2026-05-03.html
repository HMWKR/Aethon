01 Executive Summary

결론: 방향은 좋지만, 경쟁 지형이 이미 AETHON 쪽으로 움직이고 있다

AETHON의 큰 가설인 "AI 생성 + 일관성 + 타임라인 편집 + 모델 라우팅"은 여전히 강하다. 다만 이 조합은 더 이상 비어 있는 황무지가 아니다. Higgsfield는 이미 "모든 톱 모델을 한 워크스페이스에"라고 말하고, Movey/Cutflow/Story2Vid는 "씬별 스토리 제작과 캐릭터 일관성"을 정면으로 겨냥한다.

AETHON은 "AI가 대신 만드는 툴"이 아니라 "사용자가 더 좋은 선택을 책임 있게 할 수 있도록 돕는 AI-native 제작 운영체제"로 정의해야 한다. 장면이 늘어날수록 캐릭터, 세계관, 비용, 권리, 프롬프트 이력이 무너지지 않게 도와주되 최종 결정권은 사용자에게 둔다.
좋은 점

문제 정의가 날카롭다

PRD는 반복 프롬프트 입력, 캐릭터/배경/스타일 붕괴, 모델 선택 피로를 정확히 잡고 있다. 특히 S1, S2, S3처럼 검증 가능한 지표를 둔 점이 좋다.

위험한 점

증명보다 선언이 많다

현재 `apps/`와 `packages/`에는 소스 파일이 없고, `package.json`, `pnpm-workspace.yaml`, `turbo.json`, `packages/db/schema.sql`, `.claude/plans/ai-typed-dusk.md`가 없다. 사업 문서의 시장/점유율 수치도 다수 `[추정]` 상태다.

승부처

선택 보조 UX

Runway Gen-4도 일관성을 내세운다. AETHON은 "우리도 일관성"이 아니라, 사용자가 놓친 리스크와 더 나은 선택지를 보여주고 10씬/30씬/50씬의 일관성을 측정해야 한다.

03 Market Signals

시장 조사: 단발 생성에서 제작 워크플로우로 전쟁터가 이동 중

Grand View Research는 글로벌 AI 비디오 생성 시장을 2025년 7.885억 달러, 2033년 34.416억 달러, 2026-2033 CAGR 20.3%로 추정한다. 숫자 자체보다 중요한 것은 성장의 방향이다. 이제 사용자는 "한 컷이 멋진가"보다 "여러 컷을 완성 가능한가"를 묻는다.

Shift 1

모델 품질의 상향 평준화

Runway, Sora, Kling, Veo, Luma, PixVerse 모두 개별 클립 품질을 빠르게 끌어올리고 있다. AETHON의 차별점은 개별 모델 품질이 아니라 모델을 언제, 왜, 어떻게 섞는지다.

Shift 2

캐릭터 일관성의 기본 기능화

Runway Gen-4, Movey, Story2Vid, Cutflow, SteadyShot이 모두 일관성을 전면에 둔다. AETHON은 "일관성 제공"을 넘어 측정, 재시도, 실패 원인 분석까지 제공해야 한다.

Shift 3

에이전트/캔버스/스토리보드

Luma와 CapCut은 AI가 작업을 계획하고, Canva는 생성물을 편집기로 이어주며, Sora는 Storyboard와 Remix 흐름을 제공한다. AETHON의 타임라인은 생성 후 편집기가 아니라 생성 전 의사결정 판이어야 한다.

Shift 4

권리와 출처가 제품 기능이 됨

초상권, 브랜드, 저작권, AI 표시, C2PA/Content Credentials가 창작 툴의 신뢰 레이어로 부상했다. 영상 생성 툴은 법무 문구만으로 부족하다.

AETHON 시장 가설 업데이트

기존 가설 웹 리서치 후 판단 수정 제안
"AI 생성 + 일관성 + 타임라인 편집" 카테고리가 비어 있다 부분적으로만 맞다. Movey, Cutflow, Story2Vid가 직접 경쟁 영역에 있다. "비어 있다" 대신 "아직 표준 제품이 없다"로 표현을 낮추고, 비교표에 직접 경쟁자를 포함한다.
멀티 모델 라우터가 핵심 IP다 여전히 유효하지만 Higgsfield/Luma/CapCut도 다중 모델 또는 통합 워크스페이스를 강조한다. 라우터만이 아니라 프로젝트 컨텍스트, 비용, 품질 점수, 권리 상태를 함께 고려하는 "제작 결정 엔진"으로 확장한다.
캐릭터 일관성이 차별점이다 차별점에서 입장권으로 변하고 있다. 일관성 점수, 실패 샷 탐지, 재생성 정책, 캐릭터별 변화 이력으로 방어력을 만든다.
D+60에 9개 영상 모델 연동 접근 권한, 가격, 정책, 품질 변동 때문에 과하다. MVP는 3개 모델 실호출 + 나머지는 라우팅 시뮬레이션/더미 어댑터로 시작한다.
04 Competitor Review

경쟁 사이트별 장점/단점과 AETHON에 주는 압박

아래 평가는 웹사이트와 공식 문서에서 확인한 기능 메시지를 기준으로 정리했다. 실제 품질, 가격, 지역별 제공 여부는 계정/플랜/국가에 따라 달라질 수 있으므로 출시 전 재검증이 필요하다.

서비스 사이트에서 확인한 핵심 메시지 장점 단점/빈틈 AETHON 대응
Runway Gen-4
위협 높음		 Gen-4는 캐릭터, 장소, 오브젝트의 장면 간 일관성과 컨트롤을 강조한다. 브랜드 인지도, 영상 모델 품질, 프로덕션 친화 편집 도구, 영화 제작자 타깃이 강하다. Runway 생태계 안에서의 생성/편집에 무게가 있고, 여러 외부 모델을 비교 선택하는 메타 라우터는 아니다. Runway를 경쟁만이 아니라 초기 라우팅 대상 모델로 포함하되, AETHON은 "Runway 포함 여러 모델의 프로젝트 관리 레이어"로 포지셔닝한다.
Sora
위협 높음		 OpenAI 공식 도움말 기준 Storyboard, Re-cut, Remix, Blend, Loop, MP4 다운로드 흐름이 있다. Sora 앱은 캐릭터, 사운드, 스티칭을 강조한다. 자연어 이해, 스토리보드, 리믹스 UX, ChatGPT 사용층 접근성이 강하다. Sora 1 웹 경험은 전환/폐기 공지가 있고, 인물/초상 업로드 제한 및 정책 제약이 크다. AETHON은 Sora와 정면 품질 경쟁보다 프로젝트 자산, 동의, 모델 대체, 장면별 버전 관리로 차별화한다.
Higgsfield
위협 매우 높음		 "Every top model, one workspace", Cinema Studio, Camera/lens control, first/last image reference, motion control, Marketing Studio를 전면에 둔다. 픽스필드/히그스필드로 사용자가 말했을 가능성이 높은 직접 비교 대상. AETHON의 멀티 모델/시네마틱 제어 메시지와 크게 겹친다. 웹 메시지는 강하지만 프로젝트별 캐릭터 DB, RLS, 권리 이력, 비용 투명성, 개발자용 일관성 API는 AETHON이 파고들 여지가 있다. "우리도 모델 모음"이 아니라 "작품 단위 컨텍스트와 검증 지표를 유지하는 제작 운영체제"로 문구를 조정한다.
PixVerse
위협 높음		 V6는 카메라, 캐릭터 퍼포먼스, 멀티샷, 네이티브 오디오를 강조하고, R1은 실시간 1080p 인터랙티브 월드 모델을 주장한다. 사용자 규모, 빠른 모델 릴리스, 실시간/인터랙티브 비전이 강하다. 광범위한 생성 플랫폼 성격이 강해, 소규모 창작자의 편집/검수/재작업 루프를 얼마나 깊게 관리하는지는 별도 검증 필요. AETHON은 PixVerse를 모델/워크스페이스 경쟁자로 보되, "작품별 리뷰 루프와 일관성 검증"의 깊이를 차별화해야 한다.
Luma

AETHON 기술 선택에 대한 해석

MVP 웹

WebCodecs + 경량 export

초기 웹 MVP는 전체 NLE가 아니라 씬 보드, 프리뷰, 짧은 클립 조합, 간단 export에 집중한다. Mediabunny/WebAV/ffmpeg.wasm을 비교해 가장 작은 성공 경로를 잡는다.

Native FFmpeg + Rust 코어

장기 목표가 AI 영상계의 Premiere Pro라면 대용량 파일, 프록시, 안정적 export는 브라우저만으로 부족하다. Tauri + Rust + FFmpeg 쪽을 장기 코어로 둔다.

표준화

.aethon + OTIO export

내부 포맷은 AI 메타데이터를 담는 `.aethon`으로 가되, 컷/트랙/클립 정보는 OpenTimelineIO로 내보낼 수 있게 설계하면 전문가 신뢰도가 올라간다.

06 Positioning

AETHON의 포지셔닝을 더 좁고 강하게 바꿔야 한다

"AI Video Creation Studio"는 너무 넓다. CapCut, Canva, Luma, Higgsfield, OpenCut이 모두 비슷한 말을 할 수 있다. AETHON은 처음부터 자동 생성만 내세우기보다, AI 영상을 이미 만들어 본 창작자가 기획표, 레퍼런스, 모델 선택, 생성 결과, 부분수정, 최종 편집을 한 프로젝트 안에서 관리하는 AI-native NLE로 정의해야 한다.

현재 메시지

Let AI handle prompts. You direct the story.

좋은 문장이다. 하지만 경쟁사들도 "AI가 기술을 처리하고 사용자는 창작에 집중"이라는 메시지를 이미 많이 쓴다.

제안 메시지

Keep every scene loyal to the same world.

프롬프트 자동화보다 장면 간 충성도, 캐릭터/세계관/브랜드 연속성을 전면에 둔다. AETHON의 진짜 문제 정의와 더 가깝다.

전략 업데이트

최종 목표는 "AI 영상계의 Premiere Pro"다. 다만 MVP의 첫인상은 자동 생성 공장이 아니라 숙련 창작자가 원하는 순간에만 생성/추천/부분수정을 호출할 수 있는 편집 중심 작업대여야 한다. AI는 사용자가 놓친 리스크, 더 나은 대안, 현재 선택의 근거를 보여주는 도구여야 하며, 모델 추천과 부분수정은 보조 차별점이고 핵심 차별점은 책임 있는 선택을 가능하게 하는 AI 제작 메타데이터 타임라인이다.

AI 개입 철학: 자동화보다 책임 있는 선택

Default

Adviser Mode

AI가 먼저 실행하지 않고, 사용자가 놓친 문제와 더 나은 선택지를 제안한다. 추천 이유, 비용, 품질 리스크, 권리 리스크를 보여준 뒤 사용자가 결정한다.

Optional

Auto Mode

반복 작업이나 저위험 작업에서만 사용한다. 예: 썸네일 추출, 후보 프롬프트 생성, 낮은 점수 씬 재검사. 비용 발생/외부 전송/export는 별도 승인 게이트를 둔다.

Manual

Off Mode

AI 개입을 끄고 일반 편집기처럼 사용한다. 전문가가 직접 판단하고 싶은 영역, 민감한 장면, 법무 검토 전 파일에는 Off가 필요하다.

제품 원칙: AI는 책임 주체가 아니다. AETHON은 "AI가 해줬다"가 아니라 "사용자가 어떤 근거로 선택했는지"를 남기는 편집기여야 한다.

추천 포지셔닝 문장

AI 영상 창작자용

"기획표, 레퍼런스, 프롬프트, 모델 선택, 생성 클립, 최종 편집을 하나의 AI-native 타임라인에 모으세요."

전문 제작자용

"Midjourney, GPT Image, Seedance, Kling, Runway 등 외부 레퍼런스와 모델을 한 프로젝트 기억으로 연결하는 편집기."

투자자/파트너용

"AI 영상 모델들이 파편화될수록 필요한 표준 제작 레이어: 모델 선택, 일관성 검증, 권리 관리, 최종 편집/export를 하나로 묶는다."

AETHON이 반드시 가져야 할 방어 해자

해자 설명 MVP 반영 방식

Rights Ledger 업로드 레퍼런스의 소유권, 초상 동의, 상업 이용 상태 추적 업로드 시 consent/license 필드 필수화, export 시 권리 체크리스트 표시

07 UX Recommendations

UX 개선: 타임라인은 결과 편집기가 아니라 제작 판단 대시보드여야 한다

경쟁 서비스는 "한 줄 입력 → 영상"을 쉽게 만든다. AETHON은 더 복잡한 제작을 다루므로 UI가 복잡해질 위험이 있다. 따라서 화면은 창작자가 지금 무엇을 고정했고, 무엇이 흔들렸고, 다음에 어떤 결정을 해야 하는지 보여줘야 한다. 기본 AI 동작은 자동 실행이 아니라 "제안과 근거"여야 한다.

1

좌측: 고정값 라이브러리

캐릭터, 배경, 오브젝트, 브랜드, 스타일을 카드로 고정한다. 각 카드에는 일관성 점수, 사용 씬 수, 마지막 변경일, 권리 상태를 표시한다.

2

중앙: 씬 타임라인 + 스토리보드

씬 카드에는 이미지, duration, 등장 캐릭터, 선택 모델, 비용, 품질 상태를 한눈에 보인다. 드래그/복제/잠금이 가능해야 한다.

3

우측: 결정 패널

선택 씬의 프롬프트, 모델 추천 이유, 대체 모델, 인라인 핀, before/after, 로그를 모은다. 사용자가 매번 프롬프트 박스를 찾지 않게 한다.

실제 AI 영상 창작자 인터뷰에서 나온 요구

발견 제품 해석 AETHON 적용
타깃은 AI 영상을 이미 만들어 본 사람이어야 한다. 초보자용 한 줄 생성 툴보다, 여러 툴을 오가며 제작해 본 사람의 병목을 줄여야 한다. 기획표 import, 외부 레퍼런스, 모델별 프롬프트, 비용 로그, 재생성 이력을 기본 화면에 둔다.
자동 생성은 처음부터 전면 기능처럼 보이면 안 된다. 창작자는 통제를 잃는 것을 싫어한다. AI는 사용자가 옳은 선택을 하도록 돕는 제안 도구여야 한다. 기본값은 Adviser Mode. "Generate all"보다 "추천만 받기", "선택 씬 생성", "이 컷만 다시 만들기"를 우선한다.
기획표를 넣으면 씬 이미지가 좌르륵 나오고, 각각 선택 수정 가능해야 한다. 가장 강한 첫 MVP 흐름은 최종 편집기 전체가 아니라 제작 보드와 씬 타임라인이다. CSV/표 붙여넣기, 씬 카드 후보 생성/승인, 이미지 프롬프트/영상 프롬프트 분리, 씬별 모델 칩을 구현한다.
Higgsfield식 워크플로우는 내부 생성 자산에 강하고, Midjourney/GPT Image 같은 외부 레퍼런스 활용은 빈틈이 있다. 외부 레퍼런스 호환성은 AETHON의 초기 차별점이 될 수 있다. 업로드/링크 기반 레퍼런스 카드, reference provenance, 캐릭터/배경 lock, 모델별 reference compatibility 점수를 둔다.
최종 목표는 AI 영상계의 Premiere Pro다. 장기적으로는 생성 보드가 아니라 멀티트랙 편집, 자막, 오디오, 전환, export까지 가야 한다. MVP 데이터 모델을 처음부터 Track/Clip/Scene/GenerationRun/ExportManifest로 나눠 확장 가능하게 설계한다.

AI 개입 모드 설계

Mode 1

Auto Mode

사용자가 허용한 범위 안에서 AI가 자동으로 실행한다. 빠른 초안, 대량 반복, 낮은 위험 작업에 맞다. 비용 발생, 외부 업로드, 최종 export는 별도 승인 게이트를 둔다.

Mode 2

Adviser Mode

AETHON의 기본 모드다. AI가 실행하지 않고, 사용자가 놓친 요소, 대안, 리스크, 예상 비용, 품질 근거를 제안한다. 최종 선택과 책임은 사용자에게 남는다.

Mode 3

Off

AI 제안과 자동 검사를 끈다. 민감한 소재, 법무 검토 전 작업, 사용자가 직접 통제하려는 컷에서는 완전 수동 편집기로 동작한다.

08 Security, Privacy, Legal

보안/법무 보완: AI 영상 제품은 파일 저장보다 권리와 동의 관리가 더 위험하다

PRD의 보안 체크리스트는 Clerk 세션, Supabase RLS, Signed URL, PII 마스킹, OWASP를 포함해 기본 방향이 좋다. 여기에 AI 영상 특유의 초상권, 합성 고지, 상업 이용, 원본 레퍼런스 출처, 삭제권을 제품 기능으로 추가해야 한다.

제품 보안

서버/데이터 레이어

  • 모든 Server Action과 Route Handler에서 Clerk 세션과 프로젝트 소유권을 동시에 검증한다.
  • Supabase RLS는 `projects.owner_id` 기준으로 4개 메인 테이블과 Storage 경로를 묶는다.
  • AI Provider 키는 서버 전용 환경변수로만 두고, 클라이언트 번들 검사를 CI에 넣는다.
  • Signed URL은 짧은 TTL, 용도별 권한, 다운로드/공유 로그를 남긴다.
  • Job queue에는 idempotency key, retry limit, provider timeout, cancellation을 넣는다.
AI 영상 법무

권리/동의 레이어

  • 실존 인물 이미지 업로드 시 초상 사용 동의 체크와 용도 범위를 저장한다.
  • 브랜드 로고/제품 이미지는 소유권/사용권 필드를 필수화한다.
  • 생성 결과 export 시 AI 생성/편집 이력과 사용 모델을 manifest로 남긴다.
  • 상업 이용 가능 여부를 모델/플랜/소스별로 계산한다.
  • 미성년자, 정치, 성적 합성, 사칭, 의료/금융 오인 콘텐츠는 별도 정책과 차단 룰이 필요하다.

권장 데이터 필드

테이블/개체 추가 필드 목적
`assets` 신규 `source_type`, `owner_user_id`, `license_type`, `consent_status`, `retention_until`, `content_hash` 레퍼런스/생성 파일의 출처와 권리 상태 추적

`export_manifests` 신규 `project_id`, `asset_ids`, `model_runs`, `rights_summary`, `c2pa_status` 최종 MP4의 출처/권리/AI 생성 이력 관리

규제/신뢰 체크

EU AI Act

GPAI 제공자 의무는 기술문서, 저작권 정책, 학습 콘텐츠 요약 공개 등을 포함한다. AETHON이 자체 모델 제공자가 아니더라도 EU 사용자 대상 서비스라면 투명성/고지/정책 정렬이 필요하다.

미국 저작권

미국 저작권청은 AI와 저작권 보고서를 여러 파트로 발행했고, 생성물 저작권성은 인간 창작 기여가 핵심 쟁점이다. AETHON은 "사용자의 선택/편집/연출 이력"을 남겨야 한다.

C2PA/Content Credentials

C2PA는 생성/편집 provenance를 표준화하려는 기술 사양이다. 플랫폼 간 보존이 완벽하지 않아도, AETHON 내부 manifest와 export metadata는 신뢰 차별점이 된다.

Loop 2 moves AETHON beyond a professional-looking editor shell by adding the contracts that decide whether AI work can be executed or exported. The editor remains responsible for the final choice: AI exposes SceneSpec, provider capability, validation, rights, cost, and export blockers.

Core contract

`packages/core/src/production-readiness.ts` defines `SceneSpec`, `ProviderCapability`, `ValidationReport`, `CostLedgerEntry`, `RightsManifestEntry`, `ExportManifest`, and `evaluateExportReadiness`.

Editor surfaces

AI Adviser shows capability and cost/risk range. Clip Inspector shows SceneSpec, provider capability, and QC reports. Export Gate lists blockers and disables export while readiness is blocked.
