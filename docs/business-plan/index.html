03 · Solution

AETHON의 3축 통합 솔루션

창작자는 의도만 입력. 반복은 AI가, 일관성은 시스템이, 부분 수정은 영역 드래그 한 번.

🕒
M1 — TIMELINE

타임라인 + 씬 카드

스크립트 입력 → Claude Sonnet이 30개 씬 후보를 제안 → 사용자가 승인/수정 → 드래그로 순서·길이 조절. 60fps 가상화 캔버스.

  • ▸1000자 → 30씬 30초 이내 분할
  • ▸씬당 emotion·camera·intent 메타
  • ▸Konva 가상화로 60fps 드래그
🎭
M2 — CONSISTENCY

고정값 시스템

캐릭터·배경·그림체 카드를 1회 등록. IP-Adapter로 모든 씬에 자동 주입. 코사인 유사도 ≥ 0.80 보장.

  • ▸캐릭터 5명까지 다중 선택
  • ▸FLUX + IP-Adapter 가중치 0.6~0.8
  • ▸비인간 캐릭터(로봇/마스코트)도 동일 패턴
🎯
M3 — INLINE PIN

인라인 핀 재생성

이미지 위 영역 드래그 → 자연어 댓글("색만 푸르게") → FLUX Fill 부분 재생성. 평균 ≤ 2.5회 수렴.

  • ▸좌표 0~1 정규화, 5개 동시 핀
  • ▸비교 슬라이더 좌우 스와이프
  • ▸히스토리 보존 + 되돌리기
🎞️
M4 — VIDEO ROUTING

이미지 → 영상 변환 (9 모델 추천·승인)

Claude Sonnet이 씬의 emotion·duration·camera·budget을 분석해 9개 영상 AI 중 최적 모델을 추천. FFmpeg로 결합 후 MP4 Export.

04 · Differentiation

왜 AETHON만이 가능한가

모델 회사는 모델에, 편집기 회사는 편집에 집중. 그 사이의 빈 카테고리 — "AI Video Studio"를 정의한다.

01

Claude Design UX 영상 도메인 최초 접목

고정값(캐릭터·배경·그림체) + 인라인 편집(영역 드래그 + 자연어 댓글). Anthropic Claude가 UI에서 보여준 패턴을 영상 워크플로우로 첫 이식.

02

9개 영상 AI 동시 라우팅

씬 특성(duration·emotion·camera·budget)을 Claude Sonnet이 분석 → 추천 카드 표시. 이유·비용·리스크 툴팁으로 투명성 확보. 수동 오버라이드 1클릭.

03

캐릭터·배경·그림체 고정값 자동 주입

IP-Adapter + 프로젝트 단위 mood_palette·art_style 토큰. 30씬 동안 동일 캐릭터 코사인 유사도 ≥ 0.80 (S1). 단일 도구로 검증 가능.

04

인라인 영역 핀 → 자연어 부분 재생성

FLUX Fill + Nano Banana Edit. 마스크 블러 + IP-Adapter 동시 적용으로 영역 외 픽셀 영향 최소화. 외부 도구(Photoshop) 왕복 제거.
