## 1. Aethon — 10초

## 2. 제작 과정의 문제 — 30초

음악영상 한 편을 만들 때 창작자는 음원과 캐릭터 설정, 참고 자료를 준비합니다. 그다음 기획과 생성, 편집을 여러 도구에서 진행하고, 무엇을 왜 수정했는지도 전달해야 합니다. 다음 곡을 만들 때 이 맥락을 다시 연결해야 한다는 것이 저희의 문제 가설입니다. 아직 Aethon 고객 인터뷰로 검증한 내용은 아닙니다.

## 3. 왜 이 타깃인가 — 30초

그렇다면 왜 많은 영상 제작자 중 개인 VTuber와 소규모 버추얼팀부터 시작할까요? 공개 사례에서 같은 캐릭터로 여러 곡을 발표하고, 운영자가 음원과 외주, 레퍼런스와 피드백을 조율하는 과업을 확인할 수 있었습니다. 그래서 한 곡의 제작을 끝까지 해보고, 다음 곡에 설정을 다시 쓸 수 있는지를 관찰하기에 적합한 초기 대상이라고 판단했습니다. 실제 구매 의향과 반복 사용은 앞으로 확인할 가설입니다.

## 4. 솔루션 — 30초

Aethon은 IP와 음원을 정리하는 일에서 시작해, 대화형 AI가 장면 기획과 도구 사용을 돕고, 별도의 영상 모델이 생성 작업을 맡는 흐름을 지향합니다. 제작자는 장면별 후보를 비교하고 편집한 뒤 결과를 직접 검토하고 승인합니다. 현재 코드와 개발 목표를 함께 요약한 흐름이며, 영상 모델의 실제 생성 호출은 아직 검증하지 못했습니다.

## 5. 제품 화면 — 35초

이 장에 사용한 화면은 Aethon의 내부 시험 화면입니다. 제작자는 장면을 선택하고 Take 후보를 비교하며, 타임라인과 검토·승인 상태를 확인할 수 있습니다. 화면 속 색상 패턴은 시험용으로 만든 합성 미디어입니다. 실제 AI 생성 영상이나 고객이 만든 작업 사례는 아닙니다.

## 6. 개발 및 제한 시험 — 40초

현재는 프로토타입 개발과 내부 기능 검증 단계입니다. IP와 음원, 샷과 Take, 편집과 승인, FFmpeg 출력과 복구 흐름을 구현 중입니다. 기존 QA 기록에는 합성 음원과 로컬 모션을 사용한 3초 MP4 출력과, 별도 브라우저에서 2초 편집 출력을 확인한 기록이 있습니다. 이 둘은 서로 다른 제한 시험입니다.

Claude의 제한 시험 기록도 있지만 일반 사용자에게 연결한 전체 흐름은 아직 확인하지 않았고, 영상 생성 모델의 실제 호출도 검증 전입니다. 고객 인터뷰와 시험 고객, 매출은 아직 없습니다. 이 발표자료를 만드는 과정에서 제품 시험을 다시 실행한 결과는 아닙니다.

관련 활동의 배경을 보면, 2024년 글로벌 가상 크리에이터 300개 표본은 영상과 라이브, Shorts에서 합산 150억 회가 넘는 조회수를 기록했습니다. 2025년 국내 대중음악산업 매출은 전년 대비 15.8% 늘었습니다.

현재 코드에는 HTML·CSS·JavaScript, Python HTTP, SQLite와 로컬 파일, FFmpeg를 사용합니다. 대화형 AI는 기획과 도구 요청을 돕고, 영상 모델은 별도의 생성 작업을 맡는 구조를 지향합니다. 향후에는 PostgreSQL, AWS 저장·전달과 외부 GPU, Databricks 같은 데이터 처리 환경을 필요에 따라 검토합니다. 이들은 현재 사용 실적으로 말하는 것이 아니라 확장 제안입니다.
