# Aethon v7 발표자 노트

*기준일 2026-10-28 · 미리캔버스 네이티브 구성과 10쪽 최종 수정 반영 · 발표 8분 / 질의 7분*

본문 16장 발화 계획 7분 10초, 장 전환과 영상 재생 여유 50초. 실제 리허설로 계측한다. 부록은 질의 때 사용한다.

## 1. 소규모·버추얼 아이돌 기획사 AI MV 작업대 (10초)

안녕하세요. 소규모 아이돌 기획사와 버추얼 아이돌 제작 운영팀이 뮤직비디오를 기획하고 제작 과정을 정리할 수 있도록 Aethon을 만들고 있는 이성민입니다.

## 2. 제작 맥락을 하나로 연결 (25초)

한 곡의 뮤직비디오를 준비한다고 가정해 보겠습니다. 기획사나 제작팀은 아티스트와 곡의 방향을 정하고 장면을 구상한 뒤 여러 결과를 비교합니다. Aethon은 그 과정에서 자료와 선택의 맥락을 이어 주려 합니다. 아직 고객 인터뷰 전의 문제 가설입니다.

## 3. 왜 이 제작팀부터 시작할까요? (30초)

초기 대상은 소규모 아이돌 기획사와 지하·버추얼 아이돌의 뮤직비디오 제작팀입니다. 라이브 아이돌 NEKIRU는 공식 소개에서 싱글 17곡 이상을 밝히고 있습니다. 이는 반복 발매의 한 사례이지 MV 17편을 뜻하지 않습니다. 작은 조직의 제작 과정과 비용 부담, 지불 의향은 제작팀 인터뷰로 확인하겠습니다.

## 4. 자료에서 결과까지 하나의 흐름 (30초)

제작팀이 아티스트와 곡의 자료를 넣으면 대화형 AI가 장면 기획을 돕고, 영상 모델은 생성 요청을 담당합니다. 팀은 장면 결과를 비교하고 편집해 검토·출력합니다. 지금 말씀드린 것은 목표로 하는 사용자 흐름입니다.

## 5. 내부 제한 시험 화면 (35초)

현재 로컬 프로토타입에서 합성 음원과 로컬 모션을 조합한 3초 MP4를 확인했고, 별도로 브라우저 편집 출력 2초 시험도 진행했습니다. 화면에 보이는 미디어는 내부 합성 시험용입니다. 영상 모델 실호출과 실제 생성 영상은 추가로 검증하겠습니다.

## 6. 다음 작업까지 제작 맥락 연결 (25초)

제작팀이 아티스트 자료와 장면 의도, 선택한 결과를 이어 볼 수 있도록 설계합니다. 다음 곡을 준비할 때 같은 맥락을 다시 쓰는 것이 유용한지 확인할 계획입니다. 현재 고객 인터뷰, 시험 고객, 매출은 없습니다.

## 7. 시장 범위를 네 단계로 좁혀 출시 (30초)

같은 기준으로 시장을 네 단계로 나눴습니다. 글로벌 뮤직비디오 제작 소프트웨어에서 국내에 제공 가능한 영역을 정하고, 그 안에서 직접 접근과 판매, 지원이 가능한 제작 조직을 추립니다. 출시 초기에는 소규모 아이돌 기획사와 지하·버추얼 아이돌 뮤직비디오 제작팀을 공략합니다. 각 단계의 고객 조직 수와 연간 도구 지출은 미산정입니다.

## 8. 대안별 제작 방식 (25초)

제작팀은 여러 도구를 직접 조합하거나 제작을 의뢰할 수 있습니다. Aethon은 기획 자료와 장면 결과, 검토를 이어 주는 작업 흐름을 제안합니다. 가격과 품질 등은 대안과 비교 시험을 진행해야 합니다.

## 9. 구독과 사용량 과금 가설 (25초)

수익모델은 기본 구독에 생성 사용량을 더하는 방식으로 검토합니다. 승인본당 비용은 같은 기간의 생성과 재시도, 처리, 저장·전송, 지원 비용을 합해 승인된 결과물 수로 나눠 측정하겠습니다. 가격과 지불 의사는 아직 확인해야 합니다.

## 10. 생성비 시나리오와 총비용 검증 (30초)

5초 컷 60개를 확보한다고 가정하고 컷당 한 번, 두 번, 세 번 유료 생성하면 공개 단가 기준 영상 생성 API 소계는 각각 21달러, 42달러, 63달러입니다. 사용 가능한 컷이 확보된다는 가정이며 실측치는 아닙니다. 기획과 인건비, 편집, 권리, 운영은 별도입니다. Aethon 이용 요금과 실제 절감률은 미확정이며 같은 납품 조건의 총비용을 비교하겠습니다.

## 11. 현재와 향후 시스템 구조 (35초)

현재 웹 화면과 Python 서버, SQLite와 로컬 파일, FFmpeg로 프로토타입을 개발합니다. 향후에는 AWS의 저장·운영 구성, PostgreSQL과 Databricks를 필요에 따라 검토합니다. 도식에서 사용자, 플랫폼, 외부 서비스와 현재·향후를 나눠 보겠습니다.

## 12. 제작팀과 함께 사용을 검증 (30초)

다음 단계는 기획사와 제작 운영팀 인터뷰로 실제 뮤직비디오 작업 방식과 지불 의사를 확인하는 것입니다. 이어 제한된 사용 시험에서 기획과 편집, 승인 경험을 살펴보고 결과물 비용을 측정하겠습니다. 재사용이 유용한지와 유료 전환 가능성을 확인한 후 다음 단계로 나아갈 계획입니다.

## 13. 대화·이미지·영상 모델 연구 (25초)

장기적으로 기획용 대화 모델과 이미지·영상 모델을 용도별로 연구합니다. 데이터 권리와 모델 이용 조건을 확인한 뒤 허용된 범위에서 미세조정이나 증류를 검토하고, 품질과 비용 평가를 거쳐 적용하겠습니다.

## 14. 검증 후 협업 시장으로 단계적 확장 (20초)

초기 제작팀의 반복 사용과 비용을 검증한 뒤 인접 창작 작업으로 확장합니다. 필요에 따라 영상·UX와 고객 운영 역할을 보강해 더 넓은 AI 협업 제작 시장을 공략하겠습니다.

## 15. 개발과 데이터를 연결하는 1인 창업자 (25초)

현재 프로젝트는 저 혼자 진행하며, 데이터 엔지니어로 일하고 있습니다. 경복대학교 소프트웨어융합학과의 이성민이며, 한화 포탈 데이터 엔지니어링 경험이 있습니다. 네트워크관리사 2급과 AI프러덕션 기획자 1급, Databricks 데이터 엔지니어 프로페셔널 자격을 보유하고 있습니다. RealizeSoft의 수상은 과거 팀 이력입니다.

## 16. 제작팀과 함께 다음 검증 (30초)

지금 필요한 것은 소규모 아이돌 기획사와 제작 운영팀의 연결, 실제 작업에 대한 피드백, 그리고 사업화 멘토링입니다. 이를 통해 제품의 완성도와 고객 반응, 결과물당 비용을 검증하겠습니다. 아티스트의 다음 음악영상까지 이어지는 작업을 더 쉽게 만드는 가능성을 확인하겠습니다. 감사합니다.

## 17. 부록 · 비동기 영상 생성 구조 (부록 · 질의용)

질의에 따라 큐와 결과 확인, 승인 후 렌더, 재시도와 중복 방지의 설계 방향을 설명합니다. 현재 구현 완료를 의미하지 않습니다.

## 18. 숫자와 주장, 구현 상태의 출처 (부록 · 질의용)

두 수치는 인접 산업과 단일 제작사의 공개 예시입니다. 소규모 아이돌 기획사 시장의 크기나 성장률, Aethon 매출을 의미하지 않습니다.

## 19. 현재 대표 1인, 단계에 맞춰 역량 보강 (부록 · 질의용)

현재 프로젝트는 대표 1인이 진행합니다. 데이터 엔지니어로 일하고 있으며 Databricks 데이터 엔지니어 프로페셔널 자격을 보유하고 있습니다. 영상과 사용자 경험, 고객 운영, ML 역량은 필요에 따라 보강할 계획입니다.
