# Aethon v7 텍스트·데이터 검수

검수일 2026-10-28. [슬라이드 계획](slideplan.json)과 [발표자 노트](발표자노트.md)를 대상으로 slop-check의 발표자료·문장·AI 말투 3계층을 적용하고 문구를 직접 수정했다. 미리캔버스 실물 슬라이드의 글씨 크기·여백·잘림·겹침이나 발표 리허설을 검수한 기록은 아니다.

## 중요도순 수정 사항

1. **7쪽, 시장 포함관계 — 데이터 신뢰성 / 높음.** 이전 SAM 문구 “국내 제공 가능한 AI 영상 제작 소프트웨어”는 글로벌 MV 제작 소프트웨어인 TAM의 하위 집합이 아니었다. “국내 제공 가능 MV 제작 소프트웨어”로 좁히고, SOM은 그중 접근·판매·지원 가능한 국내 제작조직, LAM은 사용자가 확정한 소규모 아이돌 관련 MV 제작팀으로 명시했다. 모두 같은 조직과 연간 MV 제작 도구 지출을 기준으로 하며 금액은 미산정이다.
2. **10쪽, 비용 표현 — 모호함 / 높음.** “생성 비용의 범위를 가정해 원가 검증을 시작합니다”는 전달할 결론이 약했다. “생성 단가와 함께 승인본 총비용을 살핍니다”로 바꾸고, 유료 생성 횟수 가정과 공개 견적을 별도 영역에 둔다. 예시의 $21·$42·$63은 생성 API 소계이며 완성작의 비용이나 절감률이 아니다. 성공 컷 확보는 가정이다.
3. **2·4·6·8·11·13·14·15쪽, 반복적 설명 / 중간.** 가설·미검증을 여러 문장에 반복한 초안은 발표의 추진력을 떨어뜨렸다. 문장 수를 줄이고 대표적인 상태는 각 장의 상태 표시에 남겼다. 고객 인터뷰·시험 고객·매출이 없다는 핵심은 5쪽에서 그대로 명시한다.
4. **6쪽, 우회적 제목 / 낮음.** “무엇을 이어 주는지가 제품의 검증 포인트입니다”를 “제작 맥락을 다음 작업까지 이어갑니다”로 바꾸고, 본문·노트에서 재사용은 확인 예정임을 분리했다.
5. **9쪽, 본문 밀도 / 중간.** 긴 비용 산식을 “같은 기간 총 직접비 ÷ 승인본 수”로 줄이고 비용 구성은 노트에 남겼다. 기간과 분모가 같은 산식임을 유지한다.

## 남은 시각·내용 검수

- 7쪽은 네 범위, 시장 미산정 표시와 동일 기준이 함께 읽혀야 한다. 도형의 면적을 시장 규모나 실적처럼 사용하지 않는다.
- 10쪽은 가정, API 소계, VAT와 외주 범위 차이를 숫자 가까이에 둔다. 실측 원가나 절감률처럼 보이는 시각적 연결은 피한다.
- 15쪽은 한 명의 창업자, 자격과 과거 팀 수상 및 향후 보강 역할을 넣어야 하므로 작은 글씨가 생기면 자격과 수상 상세는 부록으로 옮기되 핵심 정체성은 본문에 둔다.
- 제목과 글만 보아도 제품 사용 장면이 이어지는지, 실제 원본 화면과 구조도가 계획대로 구현되는지는 제작 후 다시 확인한다.
- 발화 7분 10초는 배분 계획이며 실측이 아니다. 삽입 영상을 포함한 전체 시간을 리허설해야 한다.
