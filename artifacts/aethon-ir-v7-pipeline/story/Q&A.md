# Aethon v7 예상 질문과 답변

*대회 질의 7분 대비 · 2026-10-28 · 미확인 사항은 답변에서도 미확인으로 유지*

1. **누가 돈을 내고 누가 사용하나요?**  
   초기에는 소규모 아이돌 기획사나 뮤직비디오 제작 운영팀을 구매·운영 주체로 가정합니다. 출연 아티스트와 구매·사용자는 다를 수 있습니다. 실제 결정권과 업무 분담은 인터뷰로 확인하겠습니다.

2. **왜 이 대상인가요?**  
   한 아티스트의 곡과 영상 콘셉트를 연결해 관리하는 작업이 제품 방향과 맞을 가능성이 있기 때문입니다. NEKIRU의 공식 소개에 나온 싱글 17곡 이상은 반복 발매의 단일 사례입니다. 뮤직비디오 편수나 구매 수요를 뜻하지 않으며, 실제 제작 빈도와 필요는 인터뷰로 확인하겠습니다.

3. **완성된 제품과 데모가 있나요?**  
   로컬 프로토타입 개발 중입니다. 합성 음원과 로컬 모션으로 만든 3초 MP4와 별개의 2초 브라우저 편집 출력 시험은 확인했습니다. 고객 시험이나 외부 영상 모델의 실제 생성 성공을 뜻하지 않습니다. 실제 생성 영상은 확보 후 제시하겠습니다.

4. **대화형 AI와 영상 생성 모델은 왜 따로 필요한가요?**  
   대화형 모델은 사용자의 자료를 바탕으로 기획과 장면 구성을 돕고, 영상 모델은 장면 생성 작업을 맡는 방향입니다. 각 연결과 품질은 구현·시험 범위를 구분해 확인해야 합니다.

5. **이미 있는 생성 도구와 어떤 차이가 있나요?**  
   제작 자료와 기획 맥락, 생성 결과의 검토를 한 흐름으로 연결하는 방향입니다. 실제 편의성, 속도, 가격이나 품질이 기존 대안보다 낫다는 사실은 아직 검증하지 않았습니다.

6. **수익은 어떻게 내며 가격은 얼마인가요?**  
   기본 구독과 생성 사용량 과금을 검토하는 단계입니다. 가격은 정하지 않았으며 고객 지불 의사와 같은 기간의 승인본당 총비용을 측정한 뒤 결정하겠습니다.

7. **시장 규모와 LAM은 무엇인가요?**  
   LAM은 출시 초기 공략 시장으로, 소규모 아이돌 기획사·지하 아이돌·버추얼 아이돌의 뮤직비디오 제작 시장입니다. 초기 대상의 고객 수와 연간 지출을 확인하지 못해 네 단계의 금액을 산정하지 않았습니다. 국내 대중음악 매출 성장률은 인접 산업 맥락일 뿐 저희 시장의 크기나 성장률이 아닙니다.

8. **AWS와 PostgreSQL, Databricks는 이미 쓰고 있나요?**  
   현재 확인된 로컬 구성은 웹 프런트엔드, Python, SQLite·로컬 파일과 FFmpeg입니다. AWS·PostgreSQL·Databricks는 향후 데이터 규모와 운영 필요에 따른 제안 구성입니다.

9. **자체 모델이나 증류는 이미 가능한가요?**  
   현재 자체 모델은 구축하지 않았습니다. 장기적으로 대화·이미지·영상 모델 각각에 대해 권리와 약관을 확인한 데이터로 미세조정 또는 허용 가능한 증류를 연구하고, 품질·비용을 평가해 적용 여부를 정할 계획입니다.

10. **한 명이 제품을 어떻게 만들고 시장을 개척하나요?**  
    현재는 데이터 엔지니어로 일하는 대표 1인이 개발합니다. Databricks 데이터 엔지니어 프로페셔널 자격을 보유하고 있으며, 초기에는 범위를 좁혀 고객과 제품을 검증합니다. 그 결과에 따라 창작 현장·디자인·운영 역할을 확보하는 방안을 검토합니다.

11. **수상 이력은 현재 제품의 고객 실적인가요?**  
    아닙니다. 소개하는 두 상은 이전 RealizeSoft 팀의 활동 이력입니다. 현재 피벗 제품의 고객 수, 매출이나 검증 성과와 구분합니다.

12. **지원이 있다면 무엇을 검증하나요?**  
    소규모 기획사·제작팀 연결과 현장 피드백을 통해 실제 작업 방식 및 사용 가능성을 확인하고, 제한 시험에서 제품 완성도와 비용을 검증하겠습니다. 지원금 금액이나 사용 비율은 확정하지 않았습니다.

13. **장기적으로 어디까지 확장하나요?**  
    처음에는 좁은 고객군의 뮤직비디오 제작을 검증하고, 반복 사용과 비용 구조 및 운영 역량이 확인될 경우 인접 창작 작업과 더 넓은 AI 협업 제작 시장으로 확장하려 합니다. 특정 시점이나 시장 점유율은 약속하지 않습니다.

14. **사용자 작품과 학습 데이터의 권리는 어떻게 보호하나요?**  
    관련 권한과 제공 조건을 확인한 데이터만 사용한다는 원칙을 계획에 반영합니다. 외부 모델의 출력물이나 이용 약관이 학습·증류를 허용하는지는 모델별로 확인해야 하며, 확인 전에는 허용된다고 주장하지 않습니다.

15. **가성비가 어느 정도이며 외주 대비 얼마나 줄어드나요?**  
    공개 API 가격을 활용해 5초 영상 60컷, 컷당 총 1·2·3회 유료 생성이라는 시나리오를 계산하면 Kling 생성분만 $21·$42·$63입니다. 이는 실측치나 완성작 총비용이 아니며, 사람의 작업·편집·권리·운영·세금이 빠져 있습니다. 18쪽의 단일 제작사 외주 공개 견적은 VAT 별도·상담 견적이며 범위와 통화가 다르므로 절감률을 계산할 수 없습니다. 동일 납품 범위, 품질, 세금, 고객 인건비까지 맞춘 실제 시험으로 비교하겠습니다.
