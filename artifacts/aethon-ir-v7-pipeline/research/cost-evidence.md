# Aethon 비용 가설과 비교 범위

확인일 2026-10-28. 아래는 공개 요금표를 적용한 **가정 시나리오**이며 Aethon 실측 원가, 완성작 제작비, 고객 요금 또는 절감 실적이 아니다. 영상 모델 실호출 및 실제 제작·승인, 사용자 인건비, 유료 전환은 검증 전이다.

## 확인한 가격과 조건

1. [fal.ai Kling v2.5 Turbo Pro 이미지→영상](https://fal.ai/models/fal-ai/kling-video/v2.5-turbo/pro/image-to-video)은 5초 요청 $0.35, 추가 1초당 $0.07로 표시한다. [공식 가격표](https://fal.ai/pricing)도 같은 엔드포인트의 초당 $0.07을 기재한다. 모델·해상도·길이·옵션별 가격은 변하므로 계약·호출 전 재확인한다. 모델 품질, 입력 이미지 생성비, 실패 과금 여부는 이 단가만으로 확인되지 않는다.
2. [fal.ai Wan 2.1 이미지→영상](https://fal.ai/models/fal-ai/wan-i2v)은 기본 81프레임(16fps 약 5초) 영상당 480p $0.20, 720p $0.40, 기본 프레임 초과 시 1.25배를 표시한다. 이는 위 Kling과 다른 모델·품질·해상도의 **대안 가격**으로, 두 가격의 차이를 동일 품질의 절감으로 해석하지 않는다.
3. [Runpod 공식 가격표](https://www.runpod.io/pricing)(2026-10-08 갱신)는 Serverless 24GB 4090을 $1.10/시간으로 제시한다. [과금 문서](https://docs.runpod.io/serverless/pricing)는 워커 시작부터 완전 정지까지 초 단위 과금, 콜드 스타트·실행 시간과 저장 비용을 설명한다. GPU 시세는 fal 호출료에 더하는 비용이 아니라, **직접 호스팅을 선택할 때 별도의 대안**이다. 처리 시간·메모리·유휴·동시성·할당·전송과 장애 비용 실측 전에는 컷당 가격을 확정할 수 없다.
4. [Wan2.1 모델 제작자 저장소](https://github.com/Wan-Video/Wan2.1)는 T2V 1.3B의 최소 8.19GB VRAM과 RTX 4090에서 480p 5초 영상 약 4분 생성(최적화 미적용)을 소개한다. 이는 게시자의 **특정 모델·조건**이며 이미지→영상 14B 또는 Aethon 서버리스의 성능·총 청구시간이 아니다. 워커 시작·셧다운·스토리지 비용을 포함하지 않으므로 그대로 원가나 양산 속도로 주장하지 않는다.
5. 비교 견적 원문은 [밍글스튜디오](https://minglestudio.co.kr/services.html): 원테이크 MV 스튜디오 대여 60만원부터(촬영 진행·편집 등 별도), 프리미엄 제작 200만~400만원(상담 후 범위 확정, 견적 페이지 VAT 별도 표기). [스튜디오 놀](https://studionol.co.kr/ko/music-video): MV·라이브 영상 50만원부터(VAT 포함), 촬영 범위에 따른 개별 견적. 제공 범위와 부가세 조건이 다르고 둘 다 단일 업체의 공개가이므로 시장 평균이 아니다.

## 시나리오: 5분 완성본용 5초 컷 60개

각 컷의 유료 생성 결과 중 5초가 실제로 사용되고, 시간 손실·컷 겹침이 없으며 요청당 5초라는 **단순 가정**이다. 생성 배수 2·3은 컷마다 총 2·3회 과금 생성이 발생한다는 가정으로, 실패 요청 과금과 승인 확률을 일반화하지 않는다.

| 컷당 총 과금 생성 횟수 | 총 유료 5초 생성 | Kling API 생성비만 | Wan 2.1 I2V 480p API 생성비만 |
| --- | ---: | ---: | ---: |
| 1회 | 60회 | $21 | $12 |
| 2회 | 120회 | $42 | $24 |
| 3회 | 180회 | $63 | $36 |

Wan 720p 기본 프레임이면 같은 시나리오의 생성비는 $24/$48/$72다. 입력 이미지·자막·음악·인력·검토·합성·저장·전송·상용 권리·세금·환율·서비스 요금은 포함하지 않는다. 실제 영상 길이, 품질, 캐릭터 일관성, 실패 과금, 최종 승인율을 통제하지 않은 산술이며 60개가 모두 승인된다는 보장도 없다.

## 동일 범위 총비용과 손익분기

**공급자 단위경제:** 기간별 `(영상·이미지·대화 모델 청구 + 유료 실패·재시도 + 컴퓨트·합성 + 저장·전송 + 운영·지원 인건비 + 결제 수수료 + 기타 직접비) ÷ 승인된 완성본 수`. 제공사 청구서/메트릭·사람 작업시간으로 계측하며, 예외·실패도 기간 비용에 포함한다. 개발 및 고정비 배부 여부를 따로 명시한다. 자체 호스팅 시 fal 청구와 GPU 추론을 중복 합산하지 않는다.

**구매자 비교:** 같은 결과물·영상 길이·해상도·창작/촬영·시각효과·편집·자막·수정 횟수·권리·납기 기준으로 `(Aethon 구독/사용료 + 구매자 자체 기획·검수·편집 인건비 + 별도 외주·소재·권리비 + 세금)`과 `(비교 견적에 포함되지 않은 구매자 인건비·소재·권리비 + 외주 견적 + 세금)`을 비교한다. Aethon 구독료에 포함된 API 비용을 구매자 비용에 중복 가산하지 않는다. 공급자 비용과 구매자 요금은 별도이며, VAT·통화·환율 적용 시점까지 일치해야 한다.

**검증할 손익분기:** 동일 범위에서 Aethon 이용으로 절약한 사람 시간 × 인정 시간당 비용이 Aethon 이용에 추가되는 구독·사용료 및 별도 작업비를 초과하는지 확인한다. 절감 시간·단가는 인터뷰와 시험에서 수집하며, 외주 항목이 대체되면 그 실제 범위의 비교 견적을 포함한다. 실측 전 절감률·손익분기 고객 수를 제시하지 않는다.

**민감도:** 승인 컷당 생성 횟수(1·2·3회), 이미지/영상 모델과 해상도, 생성 실패·재시도 청구, 완성본 승인 수, 사람의 검수·수정 시간, 동시성 및 Runpod 워커 가동 시간, SaaS 가격, VAT·환율, 권리 및 납기 요구를 바꾸며 결과를 표시한다. 위 표는 API 비용 변동만 보여준다.
