# Aethon v7 발표자료 제작 방식과 스타일 근거

기록일: 2026-10-28. 사용자에게 선택받은 기존 미리캔버스 IR 템플릿과 v6.1 개선본을 현재 작업의 스타일 기준으로 삼는다. 이 기록은 회사 전체의 확정 브랜드 가이드가 아니다.

## 실제 자료에서 확인한 스타일

- 사용자 선호 템플릿: 미리캔버스 `design_title` 810492, 원본 1920×1080. 자료: `artifacts/aethon-ir-v6/evidence/template-manifest.json`.
- 템플릿 팔레트에 검정 `#000000`, 흰색 `#FFFFFF`, 하늘 `#7BD1FA`, 민트 `#D3FDF4`, 밝은 회색 `#EEEEEE`가 기록되어 있다. 하늘·민트의 그라데이션, 밝은 배경, 둥근 형태와 검정 텍스트를 상황에 맞게 사용한다.
- 실제 `artifacts/aethon-ir-v6/output/Aethon-IR-v6.1-MiriCanvas.pptx`의 슬라이드 XML에서 Pretendard Medium·Light·Regular와 LINE Seed Sans TH Bold·Regular가 관찰됐다. `.slides/brand.json`에는 한국어 본문의 기본 선택으로 Medium·Light를 기록하고, 보조 영문 서체도 참고사항에 남겼다. 파일에 서체명이 있다는 것만으로 미리캔버스 또는 발표 컴퓨터에 해당 서체가 설치되었음을 보증하지 않는다.
- `build-deck/scripts/init_brand.py`의 테마 자동 추출은 Calibri 및 Office 기본 악센트를 반환했다. 실제 텍스트 런·템플릿 매니페스트와 다르므로 해당 자동 추출 색과 서체를 채택하지 않았다. 템플릿의 각 페이지 레이아웃을 코드 렌더러에서 그대로 재현한다고 주장하지 않는다.

## 작업 경로와 검증

- 사용자가 미리캔버스 제작을 명시했으므로 스토리와 시각적 기준을 바탕으로 미리캔버스 API/도구와 편집 화면에서 제작·개선하고, 미리캔버스에서 PDF 및 PPTX를 내보낸 뒤 실제 출력을 검수한다.
- `build-deck`의 코드 렌더링, static guard, 토큰 스탬프, 코드 렌더 결과에 대한 lint는 이 미리캔버스 경로에서 실행했다고 주장하지 않는다. v7 결과에 대해 실제 완료된 검사와 미실시 검사는 최종 결과에서 별도로 기록한다.
- v6.1 비교 보존본에서는 미리캔버스 및 PDF로 19장을 확인했고, 수정된 5·8·14·19쪽을 재확인했다. PPTX의 XML에 19개 슬라이드, 텍스트와 표가 있음을 확인했으나 PowerPoint 앱 시각 검사는 별도로 수행하지 않았다. 세부는 `artifacts/aethon-ir-v6/review2/최종검수기록.md`.
- v7은 최신 타깃 및 비용·시장 가설을 반영하는 별도 작업이다. 슬라이드에 관찰된 사실, 제안·미구현 구조, 수치 가정과 그 범위를 구분한다.
