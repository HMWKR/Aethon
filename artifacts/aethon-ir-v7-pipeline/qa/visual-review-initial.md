# v7 미리캔버스 초기 PDF 시각 검수

2026-10-28. `review/initial-01.png`~`initial-19.png`의 1600×900 렌더 19장 직접 확인. 이 기록은 초기 출력 기준이다.

## 우선 수정

- **5쪽**: 제품 시험 화면이 슬라이드의 약 618px 폭만 차지하고 흐려 내부 UI를 식별하기 어렵다. 이미지 불투명도 확인, 화면 확대, 합성 시험·AI 생성 결과 아님 표시를 권장한다.
- **11·13·17쪽**: 구조도가 약 600px 폭이고 옅어 내부 글자를 읽기 어렵다. 원본 불투명도 확인 후 본문을 1350~1450px 폭으로 확대한다. 현행/향후 구분과 향후 계획 표시는 유지한다.
- **10쪽**: ‘생성과 작업시간의 가성비’는 실측하지 않은 시간·가성비를 판단한 것처럼 읽힐 수 있다. ‘생성비 시나리오와 총비용 검증’처럼 바꾸고 ‘실측 전, 생성 API 소계, 사용 가능 컷 확보 가정, 인건비·편집·권리·저장 등 별도, 절감률 미측정’을 읽을 수 있게 표시한다. 표의 $21/$42/$63은 5초 $0.35, 각 60컷에 유료 생성 1·2·3회라는 가정의 API 소계로 산술이 맞다.
- **15·19쪽 자격 표기 정정**: 이후 사용자가 데이터 엔지니어 프로페셔널 자격 보유와 현직 데이터 엔지니어를 직접 확인했다. Databricks와 연결한 현재 표기의 세부 분야가 미확인이라는 최초 지적은 철회한다. 다만 본인 제공 표현과 공식 영문 표기 확인 여부는 구분한다. 15쪽 현직 데이터 엔지니어 표현은 들어가 있다.

## 글자 크기·범위

- 2·3·4·6·7·9·12·14·16·18·19쪽: 카드 또는 표의 설명 글자가 약 16~20px 수준이고 카드 내부 여백이 넓다. 본문 확대와 회색 주석의 대비 개선이 필요하다. 8쪽 표 본문도 확대 여유가 있다.
- 3쪽: NEKIRU의 17개 이상은 단일 사례의 발매 싱글 수이며 ‘MV 편수 아님’ 표시가 있다. 200만~400만원 견적은 해당 제작사와 프리미엄 예상 견적이라는 범위를 카드 가까이에 두는 편이 명확하다.
- 7쪽: 시장 금액·고객 수 미산정 표시가 있다. SOM은 현재 ‘접근·판매·지원 가능한 조직’이므로 일정 기간 확보할 유료 고객의 예상과는 별개라는 가정의 경계를 유지한다.
- 18쪽: `2025 대중음악 매출 +15.8%`에는 ‘국내 대중음악산업·전년 대비’를 명시한다. 밍글은 ‘프리미엄 MV 공개 예상 견적·VAT 별도·상담에 따라 변동’으로 구체화한다. 두 수치는 타깃 시장 규모와 자사 실적이 아니다.
- 1쪽은 표지의 정보 계층과 크기가 비교적 읽힌다. 뚜렷한 문장 잘림이나 요소 간 심각한 겹침은 다른 페이지에서 발견되지 않았다.
