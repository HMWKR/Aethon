# 상세 사업계획서 검토 기록

검토일: 2026-10-28. 정본: `docs/knowledge/business-plan/BUSINESS-PLAN.md`.

- 본문 16개 장과 출처 목록, 현재·향후 구조 / AWS 비동기 처리 / 모델 고도화 그림 3종을 포함했다.
- 대표·팀 정보, 초기 아이돌 MV 타깃, TAM·SAM·SOM·LAM 및 기존 아키텍처 문서와 대조했다. 기존 사업계획의 상충하는 초기 가정은 상단에 과거 문서임을 명시하고 최신 본문을 연결했다.
- 시장·비용·기술을 독립적으로 검토했다. 시장·비용 원문 재확인 기록은 research/의 세 파일에 있다.
- 결제·수납과 회계상 매출을 구분하고, 승인본 원가의 비용·결과물을 같은 프로젝트 묶음으로 맞췄으며, 외주 예상 견적의 VAT 별도 조건을 본문에 반영했다.
- 60컷 × 총 유료 생성 배수 1/2/3 × 0.35달러 = 21/42/63달러를 십진수로 확인했다. 완성 MV 원가나 실측 절감률이 아니다.
- 본문 로컬 링크 18개와 그림 3개는 모두 존재한다. 본문 근거 ID가 사업 온톨로지에 존재함을 확인했다. 파일 해시는 document-checks.json에 기록했다.
- 신규 공식 생성 단가와 반복 발매 사례를 출처·한계와 함께 등록했다. 온톨로지 검증은 117개 노드·167개 관계, 오류 0이며 관련 테스트 16개가 통과했다. 영향 조회는 수익모델·재무 및 시장·경쟁 장으로 연결됨을 확인했다.
- 이전 문맥의 변경 감지를 확인한 뒤 사업계획용과 발표용 최신 문맥을 다시 생성했고 두 context-check가 모두 통과했다. 문맥 검증은 구조와 로컬 변경 검사이며 외부 원문의 사실성 보증은 아니다.
- 제품 재실행, 실제 모델 호출·결제, 고객 인터뷰, 고객 사용 시험은 수행하지 않았다. 기술 상태는 기존 코드 조사와 2026-10-27 QA 범위를 사용했다.
- 시장 금액·조직 수, 판매가, 실측 총원가·절감률, 출시 일정, 예산·조달액은 미확정으로 유지했다. 제출 기관의 지정 서식을 적용한 최종 제출본은 아니다.
- 이번 작업은 사업계획 본문과 공통 문서 갱신이다. 기존 미리캔버스 PPT를 수정하거나 새로 내보내지 않았다.
