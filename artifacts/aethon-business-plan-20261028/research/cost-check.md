## 2. 60컷 생성비: 산술 검증된 가정

가정은 **5초 컷 60개**와 컷당 **총 유료 생성 횟수 1·2·3회**다. 추가 재시도 횟수가 1·2·3회라는 뜻이 아니다. 표의 금액은 생성 API 소계이며, 성공·채택·최종 승인이나 동일 인물·스타일 유지가 보장된다는 의미가 아니다.

`생성 API 소계(USD) = 목표 컷 수 60 × 컷당 총 유료 생성 횟수 r × 5초 요청 단가 0.35`

| 컷당 총 유료 생성 r | 유료 요청 수 | 계산 | API 소계 |
|---:|---:|---|---:|
| 1회 | 60회 | 60 × 1 × 0.35 | **US$21** |
| 2회 | 120회 | 60 × 2 × 0.35 | **US$42** |
| 3회 | 180회 | 60 × 3 × 0.35 | **US$63** |

십진수 연산으로 21.00 / 42.00 / 63.00을 재계산했다. 60 × 5초 = 300초(5분)는 모든 컷의 5초 전체를 중복·손실 없이 사용한다는 단순 조립 가정이다. 실제 트리밍·전환·불채택이 있으면 유효 길이와 필요한 요청 수가 달라진다. 실패 요청이 실제로 과금되는지와 과금 취소는 제공사 청구 정책·청구 내역으로 확인한다.

미포함: 입력 이미지와 대화 모델, 별도 음원·권리·소재, 기획·검수·수정 인건비, 합성·인코딩, 저장·전송, 서비스 운영·지원, 결제 수수료, 세금 및 환율. 금액을 원화로 환산하지 않았으며, 위 API 소계만으로 외주 대비 절감액·절감률을 계산하지 않는다.

## 3. 이중 계산을 막는 비용 경계

- **외부 추론 API와 자체 GPU:** 동일한 영상 생성 작업에서 fal API 비용과 RunPod 등 자체 GPU 추론 비용은 보통 대안이다. 실제 혼합 운영을 했다면 API 처리분과 자체 처리분을 각각 구분한 뒤 합한다. API 제공사 내부 GPU 비용을 다시 더하지 않는다. 별도로 실행한 FFmpeg 합성 등은 실제 사용량만 추가한다.
- **공급자 원가와 구매자 비용:** Aethon이 부담한 API 원가와 고객이 내는 구독·사용료는 관점이 다르다. 고객 요금에 생성비가 포함됐다면 고객 비용 비교에서 같은 API 비용을 다시 더하지 않는다. 고객의 직접 결제형 API 이용이 실제 있다면 그 금액만 별도 항목으로 둔다.
- **인건비·간접비:** 직접 작업·지원 시간을 변동비에 넣었다면 같은 인건비를 고정비에 중복 배부하지 않는다. 고정 개발비·고정 운영비와 건별 직접비를 구분하고 배부 방식을 기록한다.
- **단가의 범위:** 모델·해상도·길이·입력·권리 조건이 다른 가격은 대안 단가다. 가격 차이를 동등 품질의 원가 절감으로 표현하지 않는다.

## 4. 실제 가성비를 검증할 비교식

먼저 영상 길이·해상도·캐릭터 일관성·기획/촬영/모션 범위·편집·자막·수정 횟수·권리 귀속·납기를 동일하게 정의하고 승인 기준을 고정한다. 비교 조건이 다른 비용은 항목별 차이로 설명한다.

- **고객의 Aethon 총비용** = 구독·사용료 + 고객의 기획·검수·편집 시간 × 합의한 시간당 비용 + 포함되지 않은 외주·소재·권리비 + 해당 세금.
- **고객의 비교 방식 총비용** = 동등 범위의 실제 외주 견적 또는 기존 도구 요금 + 견적/요금에 포함되지 않은 고객 작업 인건비·소재·권리비 + 해당 세금.
- **관찰 절감액** = 비교 방식 총비용 − Aethon 총비용.
- **관찰 절감률** = 관찰 절감액 ÷ 비교 방식 총비용 × 100. 비교 기준 비용이 0보다 크고, 품질·권리·납품 범위와 통화·환율 기준일·VAT 취급이 맞을 때만 계산한다.

현재는 실측 총비용과 확정 요금이 없어 절감액·절감률을 산출할 수 없다. 밍글의 공개 예상 견적과 US$21~63은 각각 납품 서비스와 생성 API 일부 비용이므로 직접 절감률 비교에 사용하지 않는다.

## 5. 사업계획서에 제안할 단위경제·매출·손익분기 산식

아래는 **측정·계획용 산식**이며 재무 전망 수치가 아니다. 원가 항목과 기간은 원장 및 회계 분류에 맞춰 확정한다.

| 지표 | 산식 및 조건 |
|---|---|
| 승인 완성본당 직접비 | 동일 범위의 프로젝트 묶음에서 발생한 실제 직접비 합계 ÷ 승인 완성본 수. 직접비에는 실제 과금 생성·재시도, 대화/이미지 처리, 별도 합성·저장·전송, 건별 지원·권리비 등을 포함. 승인 수가 0이면 계산 불가이며 실패 비용을 없애지 않음 |
| 월 서비스 매출 | 요금제별 `월 환산 유료 이용 단위 × 부가세 제외 기본 요금`의 합 + 과금 가능한 사용량 × 부가세 제외 사용 단가 − 할인·환불. 일할·선수금·수익 인식은 별도 분리하며 실제 회계 매출은 회계 기준으로 확인 |
| 구독 MRR / ARR 환산 | 반복 구독분의 월 정상화 순액을 MRR로, `MRR × 12`를 연환산 실행률로 표시. 비정기 사용량 매출은 분리. ARR 환산을 향후 1년 매출 확정치로 쓰지 않음 |
| 고객당 월 공헌이익 | 부가세 제외 고객당 월 순매출 − 동일 고객을 제공하는 데 추가로 드는 월 변동 직접비. 사용량·지원 수준별로 다르면 고객군별 계산 |
| 월 손익분기 유료 고객 수 | `월 고정비 ÷ 고객당 월 공헌이익`을 올림. 공헌이익이 양수이고 고정비·가격·사용량·고객 믹스가 해당 범위에서 유지될 때만 유효. 단계적 인력·컴퓨트 증설 시 다시 계산 |
| 여러 요금제의 손익분기 조건 | `Σ(요금제별 유료 고객 수 × 해당 고객당 공헌이익) ≥ 월 고정비`. 고객군 구성이 없으면 단일 BEP 고객 수를 확정하지 않음 |
| 월 계획 손익 | 부가세 제외 순매출 − 변동 직접비 − 고정비. 실제 회계 영업손익과 같다고 단정하지 않고 비용 분류·감가상각 등 범위를 명시 |
| 현금 소진·자금 필요 | 월말 가용현금 = 전월말 현금 + 실제 현금 유입 − 실제 현금 유출. 매출·이익과 현금 수납 시점을 구분. 조달 필요액은 기간별 최소 현금잔액과 승인된 계획을 확인한 뒤 결정 |
